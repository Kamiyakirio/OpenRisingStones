# 配装编辑器

Mode: Operate。继承根目录 [DESIGN.md](../../DESIGN.md)，不另建主题或全局导航。

## 任务结构

首次使用先选择职业或导入分享码，不预选学者，不自动创建已保存方案。命令栏保留方案、职业、保存状态与明确的“保存方案”；等级、同步、种族和方案名收进“方案设置”。新建、导入、复制和编辑均先保留为内存草稿，只有保存按钮、保存并继续、另存优化方案会写文件。打开已有方案不写文件。
编辑区使用配装、属性/比较、最优配装三个任务。换装保持同屏操作：桌面左边为整套装备，右边为所选部位的候选列表；左栏随窗口扩展且不低于 380px，镶嵌轨道另起一行，为名称、属性和操作按钮保留空间。窄窗口上下排列并保留两区。候选区提供部位选择器与下一部位操作，也可直接点击左侧其他装备切换。切换任务保留当前槽位与草稿。切换方案、新建、导入、更换已配装职业、离开配装页时，未保存修改需要选择保存并继续、不保存继续或取消；浏览器刷新使用原生离开提示。

当前配装的武器独占顶部一行，与下方留出 24px 间距；副手存在时紧随武器。左列依次为头、身、手、脚、腿，右列依次为耳环、项链、手镯、两个戒指；食品、药品与特殊槽位另列在底部。窄屏按分组改为一列。每行以装备缩略图或空槽占位开头，名称下方直接列出完整的当前生效属性，包含主属性、武器性能和副属性，无需打开弹窗。数值随镶嵌、自定义属性和同步更新；消耗品显示实际加成。装备锁定和魔晶石锁定保持独立。

候选浏览默认不限品级、不隐藏过时装备，按品级降序显示。品级和每项属性均可切换升序、降序。筛选在文档流中展开，不覆盖操作按钮；收起后仍显示范围和排序摘要，并提供清除搜索与筛选。获取途径根据当前搜索词、职业、部位、品级和过时开关联动，统计覆盖全部结果页；来源维度本身不缩掉其他可切换来源。已选来源在新条件下无匹配时明确标识，保留用户选择并提供清除入口，不自动放宽范围。装备、食品、药品和专家证分别保留浏览条件。

候选行包含装备图标、名称、品级与来源、属性和固定五列魔晶石轨道。战斗职业显示三项核心副属性，并始终追加对应的技速或咏速；生产职业保留三项生产属性。两、三、五孔始终按同一轨道对齐，禁断孔使用虚线边界，HQ 仍是克制的文字标记。

## 图标数据

数据生成器从已纳入转换流程的 `Item.csv` 读取 `Icon`，在唯一的 `catalog.json` 中保存数值 `iconId`。这不会增加装备图片文件，也不会在搜索或切换筛选时请求 Item sheet。

界面根据 `iconId` 生成 XIVAPI asset URL，按需加载 80×80 高分辨率游戏图标。XIVAPI 官方允许直接引用资产并提供 ETag 缓存。职业选择同样使用 XIVAPI 的职业图标路径。

资产加载失败或离线时隐藏损坏图片并显示固定尺寸的本地图标占位，行高和列对齐不发生变化。外部图标为装饰图像，装备名称仍是可访问名称。

## 行为

选择候选就在列表上方预览属性与 GCD 变化，可以取消；“替换装备”或再次按 Enter 才应用到草稿，应用后显示结果并可撤销。候选列表局部滚动，分页与调整筛选会回到列表顶部。
当前装备行可以直接打开镶嵌；候选页也保留“编辑镶嵌 / 属性”。弹窗标识目标装备，承载镶嵌、自定义属性、单件实际属性与上限、移除操作，支持 Escape 与遮罩关闭并把焦点还给原触发按钮。弹窗继承应用明暗主题。

页面内单件属性使用“基础值 + 魔晶石实际加成”显示，加成使用主题成功色，保留 `+` 符号。加成按装备上限截断，品级同步导致魔晶石不生效时不显示加成；自定义属性仍计入基础部分。

装备名沿用 Asvel 的获取途径优先配色规则：点数红色，天书与绝境紫色，其余按稀有度显示普通、绿、蓝、紫、红。复用仓内 colors.json 配置，在当前装备、候选、替换预览、镶嵌详情和优化结果中保持一致；选中状态保留名称颜色，明暗主题分别保证可读性。

加入属性后，装备图标、镶嵌按钮与锁定按钮以整行高度垂直居中。候选表头不为图标预留左侧空白，固定表头遮住滚动中的图标。食品与药品显示当前配装的实际加成及利用率，不显示魔晶石列；悬停属性查看上限，利用率定义为实际加成总和除以上限总和，计算前扣除已装备消耗品的加成。图标镜像失败时回退至 XIVAPI 官方资产接口，避免镜像版本滞后导致新装备永久显示占位图。
优化范围独立于浏览筛选，明确标注当前版本推荐品级可以修改。优化获取途径只呈现该职业与计算品级范围内实际存在的装备来源，并提供逐件排除入口。计算与取消持续可达，无效范围在计算前解释原因，结果比较后才能应用到草稿或明确另存。

基础装备、筛选、普通属性和方案编排由 TS 管理；只有最优搜索将完整数值输入交给 Rust。图标加载不经过 IPC。

## 视觉与验证

使用暖白/暖黑表面、系统无衬线字体和克制金色。表格数值采用 tabular-nums；名称自然换行，数值右对齐。图标只用于槽位识别、真实装备外观和少量操作，不替代不明确的文字标签。

2026-09-16 使用 Chromium 检查 1440×900、1024×700 和 720×520，以及明暗主题、首次选择职业和完整功能流程，无整页横向溢出。浏览器使用隔离存储适配器，优化调用真实 Rust solve 程序。逐项预期、原行为、修复和验证边界见 [交互体验记录](gearing-interaction-review.md)，截图与操作日志位于忽略目录 `.impeccable/review/`。

Impeccable launcher 缺少引擎，因此不宣称自动检测通过。完整 Tauri 测试程序启动时报 Windows 入口点缺失（0xc0000139）；原生存储模块单独测试通过。浏览器证据不代表安装包或完整桌面 IPC 已经验证。
