# 配装编辑器

Mode: Operate。继承根目录 [DESIGN.md](../../DESIGN.md)，不另建主题或全局导航。

## 任务结构

命令栏保留方案、职业、保存状态与方案操作；等级、同步、种族和方案名收进“方案设置”。
编辑区使用四个互斥任务：当前配装、选择装备、属性/比较、最优配装。切换任务保留当前槽位、候选预览与草稿。

当前配装使用两列槽位清单，窄屏改为一列。每行以装备缩略图或空槽占位开头，名称为主信息，槽位和品级合并为一行辅助信息。装备锁定和魔晶石锁定保持独立。

候选页默认只显示搜索和“筛选”。品级范围、获取途径、排序及过时装备开关在筛选浮层中展开，浮层内输入框和下拉框统一为 40px 高。候选行包含装备图标、名称、品级与来源、属性和固定五列魔晶石轨道。战斗职业显示三项核心副属性，并始终追加对应的技速或咏速；生产职业保留三项生产属性。两、三、五孔始终按同一轨道对齐，禁断孔使用虚线边界，HQ 仍是克制的文字标记。

## 图标数据

数据生成器从已纳入转换流程的 `Item.csv` 读取 `Icon`，在唯一的 `catalog.json` 中保存数值 `iconId`。这不会增加装备图片文件，也不会在搜索或切换筛选时请求 Item sheet。

界面根据 `iconId` 生成 XIVAPI asset URL，按需加载 80×80 高分辨率游戏图标。XIVAPI 官方允许直接引用资产并提供 ETag 缓存。职业选择同样使用 XIVAPI 的职业图标路径。

资产加载失败或离线时隐藏损坏图片并显示固定尺寸的本地图标占位，行高和列对齐不发生变化。外部图标为装饰图像，装备名称仍是可访问名称。

## 行为

选择候选只预览差异；“替换装备”或再次按 Enter 才应用，应用后可撤销。
当前装备通过“编辑镶嵌 / 属性”打开独立 popup；总属性页只呈现整套方案结果。popup 标识目标装备，承载镶嵌、自定义属性和移除操作，支持 Escape 与遮罩关闭并把焦点还给触发按钮。
优化范围独立于浏览筛选。计算与取消持续可达，结果比较后才能应用或另存。

基础装备、筛选、普通属性和方案编排由 TS 管理；只有最优搜索将完整数值输入交给 Rust。图标加载不经过 IPC。

## 视觉与验证

使用暖白/暖黑表面、系统无衬线字体和克制金色。表格数值采用 tabular-nums；名称自然换行，数值右对齐。图标只用于槽位识别、真实装备外观和少量操作，不替代不明确的文字标签。

Chrome 已检查 1440×900、1024×700 和 720×520：任务切换、筛选浮层、真实 XIVAPI 图标、加载失败占位和装备应用均无整页横向溢出或页面异常。截图位于忽略目录 `.impeccable/review/`。

Impeccable launcher 与 detector 仍以退出码 1 无输出结束，因此不宣称自动检测或像素差异检查通过。浏览器证据不代表 Windows 原生字体、安装包或离线网络环境已经验证。
